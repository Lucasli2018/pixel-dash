# 像素狂奔 · PIXEL DASH

一款**双击即玩 / 浏览器即开**的横版无尽平台跳跃小游戏。单文件 HTML，零依赖、零构建、无需联网。

> **v5 更新**：新增**场景专属机关**——雪原冰面打滑加速、熔岩喷火柱（预警→喷发）、深海气泡喷口（托举上升）、霓虹都市激光栅栏（明暗节奏）；精英 Boss 增加**飞行变体**（悬停扇翅，踩中会下压）；成就扩至 **13 项**。
>
> **v4 更新**：画布物理分辨率提升至 **1928×1024**（逻辑坐标 480×270 等比放大居中，画面锐利不变形），场景主题从 4 套扩充到 **10 套**（新增雪原/熔岩/深海/霓虹都市/沙漠绿洲/晨雾竹林，各带专属环境粒子）。
>
> **v3 更新**：精英 Boss（3 血 + 血条 + 击败爆道具）、5 款成就解锁皮肤（带轻被动）、每 100m 里程碑奖励，成就扩至 10 项。

## 怎么玩

双击 `index.html` 用浏览器打开即可。

| 操作 | 键盘 | 触屏 / 鼠标 |
|------|------|-------------|
| 跳跃 | 空格 / ↑ / W | 点击或触摸画面 |
| 二段跳 | 空中再按一次跳跃键 | 空中再点一次 |
| 短跳 / 高跳 | 轻点 / 长按跳跃键 | 轻点 / 长按 |
| 暂停 / 继续 | P / Esc | 右上角 `Ⅱ` 按钮 |
| 静音 / 开启 | M | 右上角 `♪` 按钮 |
| 重新开始 | R | 结束后点击画面 |
| 选难度（菜单） | ← → 或 1/2/3 | 点击难度格子 |
| 换皮肤（菜单） | Q / E 或 4~8 | 点击皮肤格子 |
| 返回菜单（结算） | B | 点击「返回菜单」 |

角色自动向右奔跑，你要做的是：**跳过深渊缺口、吃金币、踩扁史莱姆、捡道具、击破精英**，活得越久分数越高。踩怪要从上方落下踩中，侧面撞到会扣血。连续吃金币/踩怪会累积 Combo，生命耗尽即结算，最高分与成绩自动保存到本地。

## 难度分级

开局菜单用 ← → 或数字键 1/2/3 选择（触屏点难度格子），三档差异：

| 难度 | 生命 | 起始速度 | 速度上限 | 平台缺口 | 怪物密度 |
|------|------|----------|----------|----------|----------|
| 简单 | 5 | 120 px/s | 200 | 22–52 px | 低 |
| 普通 | 3 | 150 px/s | 255 | 28–68 px | 中 |
| 困难 | 2 | 185 px/s | 310 | 36–82 px | 高 |

## 道具系统

平台上随机刷出三种道具（漂浮发光方块，标注 S/M/D），拾取后右上角显示状态与剩余时间：

| 道具 | 图标 | 效果 |
|------|------|------|
| 护盾 SHIELD | S（青色） | 免疫一次伤害，抵挡时破碎并闪烁提示 |
| 磁铁 MAGNET | M（粉色） | 8 秒内自动吸附 95px 内的金币（幽灵皮肤扩大到 115px） |
| 冲刺 DASH | D（绿色） | 5 秒内加速 1.55 倍、免疫伤害，可直接撞碎史莱姆得分 |

## 精英 Boss

跑到 **250m** 首次遭遇精英史莱姆，之后每 **300m** 再出现一次，出现顺序循环。它是戴王冠的强化大史莱姆：

- **3 点血**：需要从上方踩 3 次（冲刺撞击也能扣血），头顶与屏幕顶部都有血条。
- **受击锁定**：被踩中后短暂免疫连踩 0.6 秒，防止一次下落瞬间打空血条。
- **击败奖励**：+200 分 × 连击倍率，屏幕震动 + 金色粒子爆发，**必定掉落一个道具**，并解锁成就「巨人杀手」。
- 侧面撞到它照样扣血——要么踩它，要么绕开。
- **飞行变体（v5）**：从第二个精英起有 50% 概率刷出飞行精英——扇着翅膀悬浮在空中上下巡航，移动更快；踩中一次会被压低一点飞行高度，逐层把它踩回地面附近再收尾。屏幕顶部血条标注 `FLY` 区分。

## 场景专属机关

v5 起，四类场景拥有专属机关（首次进入对应场景时提示条会带说明），让场景不只是换皮：

| 场景 | 机关 | 效果与应对 |
|------|------|------------|
| 雪原 ❄ | 冰面平台 | 部分平台结冰（带高光），跑上去速度 ×1.25——赚距离更快，但缺口来得更急，起跳时机要提前 |
| 熔岩 🌋 | 喷火柱 | 地面火山口按节奏运作：静止 → 红光预警 0.5 秒 → 喷发火柱 0.6 秒（高 38px，可跳过）。碰到火柱扣血，全程在喷发时从旁跑过累计 6 次解锁「火焰舞者」 |
| 深海 🌊 | 气泡喷口 | 地面喷口持续冒气泡，站进气泡柱会被托举上升（相当于免费电梯），借力能吃到高处金币；乘气泡 12 次解锁「气泡骑士」 |
| 霓虹都市 🌃 | 激光栅栏 | 地面与浮空发射器之间的激光柱：熄灭 1.2 秒 → 点亮 1.0 秒循环，点亮时碰到扣血。读节奏穿行，像跳绳一样过激光 |

机关伤害同样吃护盾抵挡与冲刺无敌；喷火柱喷发前有明显预警，激光有固定节奏，都可预判。雪原冰面累计滑行 8 秒解锁「冰上飞驰」。

## 角色皮肤

菜单里用 Q / E 或数字键 4~8 切换（触屏点皮肤格子）。皮肤靠**成就数量**解锁，纯外观 + 轻微被动，不影响核心平衡：

| 皮肤 | 解锁条件 | 被动效果 |
|------|----------|----------|
| 探险家 | 默认 | 经典配色，无被动 |
| 幽灵 | 2 项成就 | 磁铁吸附范围 +20px |
| 熔岩 | 4 项成就 | 踩怪得分 +5 |
| 暗影 | 6 项成就 | 受伤无敌时间 +0.15 秒 |
| 黄金 | 8 项成就 | 全部得分 ×1.05 |

未解锁的格子会显示所需成就数，点击会提示而不是直接切换。选中的皮肤会记住，下次打开仍是它。

## 场景主题与里程碑

- **10 套场景循环**：每 400m 切换一次，顺序为 **① 黄昏 → ② 夜晚 → ③ 黎明 → ④ 白昼 → ⑤ 雪原 → ⑥ 熔岩 → ⑦ 深海 → ⑧ 霓虹都市 → ⑨ 沙漠绿洲 → ⑩ 晨雾竹林 → 回到黄昏**（每 4000m 完整循环一轮）。天空、山峦、城市灯光、地面配色都会随场景整体变化；切换时用 3 秒颜色插值平滑过渡，不会突然闪变色。
- **专属环境粒子**：每个主题配有自己的氛围粒子（屏幕空间缓慢飘动，切换时淡入淡出）——雪原飘雪花、熔岩上升火星、深海气泡、霓虹都市闪烁光点、沙漠横向飘沙、晨雾竹林落叶、黎明浮尘；黄昏/夜晚/白昼保持原样（星空与落日已足够）。
- **里程碑**：每跑满 100m 触发一次，+50 分并弹提示条；单局触发 5 次（500m）解锁成就「里程达人」。

## 排行榜与成就

- **本地排行榜**：每局结束自动记录得分/距离/金币/难度，保留 Top 5 存于 `localStorage`，结算页展示前三名。
- **成就系统（13 项，解锁时弹提示条）**：
  - 金币新手：拾取第一枚金币
  - 史莱姆克星：踩/撞累计 10 只
  - 连击大师：达成 10 连击
  - 五百米 / 千米跑者：单局跑够对应距离
  - 富甲一方：单局 50 金币
  - 硬核狂奔：困难难度跑够 300m
  - 巨人杀手：击败首个精英 Boss
  - 里程达人：单局触发 5 次里程碑
  - 毫发无伤：单局不受伤跑够 300m
  - 冰上飞驰：单局冰面滑行累计 8 秒
  - 火焰舞者：单局从 6 次喷发中的火柱旁跑过
  - 气泡骑士：单局乘气泡上升 12 次

菜单底部显示解锁进度 `n/13`，结算页列出本局新解锁的成就。

## 计分与生命规则

| 项目 | 得分 / 规则 |
|------|-------------|
| 奔跑距离 | 每前进 1 像素 +0.12 分（黄金皮肤 ×1.05） |
| 金币 | 每枚 +10 分 × 连击倍率 |
| 踩怪 | 每只 +25 分 × 连击倍率（熔岩皮肤 +5） |
| 冲刺撞怪 | 每只 +15 分（冲刺状态下直接撞碎） |
| 精英 Boss | 每次踩中 +40 分，击败 +200 分（均 × 连击倍率） |
| 里程碑 | 每 100m +50 分 |
| 连击倍率 | `1 + ⌊combo ÷ 5⌋`，即 5 连击 ×2、10 连击 ×3…… |
| 连击时效 | 2.2 秒内未拾取金币/踩怪则连击清零 |
| 生命 | 按难度 2/3/5 条，撞怪侧面或坠入深渊各扣 1 条（护盾/冲刺可免疫） |
| 受伤无敌 | 扣血后 1.2 秒无敌（暗影皮肤 +0.15 秒），角色闪烁 |
| 坠崖重生 | 掉出画面后扣血并回到最近站立的平台上方继续跑 |
| 速度递增 | 随距离从起始速度逐步加速到上限（冲刺期间 ×1.55） |

> 小技巧：连击倍率对踩怪和 Boss 收益很可观，攒到 5 连击后再连续踩怪能快速拉分。

## 技术实现

- **固定步长物理循环**：累加器驱动 `update(STEP)`，渲染与物理解耦，避免高刷屏速度异常和低帧率穿模。
- **程序化无限地形**：按视野动态生成平台段（`generateAhead`），离开视野的段/金币/怪物自动回收（`recycle`），内存不随游玩时长增长。
- **手感调优**：土狼时间 + 跳跃缓冲 + 可变跳跃高度（松手短跳）+ 二段跳。
- **单向平台碰撞**：仅在下落时检测平台顶面，从下方跳跃可穿过，配合分轴约束避免卡墙。
- **程序化音效**：Web Audio API 实时合成跳跃、金币、踩怪、受伤、死亡、Boss 警报/受击/击败、里程碑、场景切换、换肤等音效，外加 8-bit 循环背景旋律，无任何外部素材依赖。
- **视差像素背景**：星空闪烁、日落/月牙、远山（0.15）、近山（0.32）、城市剪影（0.5）多层视差滚动，叠加 CRT 扫描线滤镜。
- **10 场景主题与环境粒子**：十套配色切换时按 `hex2rgb/mixHex` 对每个颜色分量线性插值 3 秒，星空亮度、月牙遮挡也随场景平滑过渡；每套场景配专属环境粒子（雪/火星/气泡/霓虹/沙/竹叶），用种子 + 时间戳在屏幕空间循环飘动，切换时淡入淡出，粒子数少（≤34）不拖累帧率。
- **精英 Boss 状态机**：`hp` 计数 + `hitT` 受击锁定防止连踩瞬杀，头顶血条与屏幕顶部血条双显示，击败后掉落道具进入既有拾取流程；v5 起有地面/飞行两种变体，飞行版用 `baseY + sin(ph)` 悬浮巡航，被踩会压低高度。
- **场景机关系统（v5）**：`hazardList` 独立管理喷火柱/激光/气泡喷口，按段的世界坐标换算所属场景决定是否生成；喷发与点亮状态用循环相位驱动，伤害走 `hurt('enemy')` 通道，天然继承护盾抵挡与冲刺无敌；机关随视野回收，内存不增长。
- **皮肤被动系统**：用 `scoreMult/magnetRange/invulnTime` 三个函数集中注入被动效果，不散落在各逻辑分支，便于扩展。
- **粒子与反馈**：拾取/踩踏/受伤/BOSS 击败粒子爆发、浮字、屏幕震动、受击闪白、命中慢动作。
- **本地持久化**：最高分、Top 5 排行榜、成就解锁状态、已选皮肤存 `localStorage`，带异常兜底（隐私模式不崩溃）。
- **高清画布 + 全端自适应**：canvas 物理分辨率 1928×1024，游戏逻辑仍用 480×270 坐标系；渲染时 `setTransform` 等比放大（≈3.79×）并居中 letterbox，画面锐利不变形，鼠标坐标按物理→逻辑反算保证点击精准；CSS 显示尺寸随窗口等比缩放，键盘 + 触屏 + 鼠标统一输入层，viewport 禁止缩放适配移动端刘海屏。

## 本地运行与部署

- **作为网页打开**：双击 `index.html` 直接用浏览器打开（Chrome / Edge / Firefox / Safari），或在项目目录执行 `python -m http.server 8000` 后访问 `http://localhost:8000/index.html`——两种方式画面一致，画布均为 1928×1024 物理分辨率、按窗口等比缩放显示。
- **部署**：纯静态单文件，可直接丢到 GitHub Pages、Cloudflare Pages、Gitee Pages 或任意静态托管，无需构建步骤。
- **全屏建议**：按 `F11` 进入浏览器全屏，画面会自动铺满屏幕（保持 1928:1024 比例，超宽屏两侧可能有细黑边）。

## 已知限制

- 音效依赖浏览器 Web Audio，首次点击/按键后才会解锁发声（浏览器策略，属正常现象）。
- 画布物理分辨率固定 1928×1024，游戏内容按 1928:1024 比例等比居中显示；在比例不符的屏幕上（如超宽屏）会有 letterbox 黑边，属正常现象。
- 最高分、排行榜、成就、皮肤存于 `localStorage`，清理浏览器数据后会重置；跨设备不同步。
- 排行榜仅本机 Top 5，非联网排行。
- 皮肤为纯外观 + 轻微被动，不做能力差异过大的设计，避免破坏难度平衡。
