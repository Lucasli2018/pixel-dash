# 像素狂奔 · PIXEL DASH

一款**双击即玩**的横版无尽平台跳跃小游戏。单文件 HTML，零依赖、零构建、无需联网。

## 怎么玩

双击 `index.html` 用浏览器打开即可。

| 操作 | 键盘 | 触屏 / 鼠标 |
|------|------|-------------|
| 跳跃 | 空格 / ↑ / W | 点击或触摸画面 |
| 二段跳 | 空中再按一次跳跃键 | 空中再点一次 |
| 短跳 / 高跳 | 轻点 / 长按跳跃键 | 轻点 / 长按 |
| 暂停 / 继续 | P / Esc | 右上角 `Ⅱ` 按钮 |
| 静音 / 开启 | M | 右上角 `♪` 按钮 |
| 重新开始 | R | 结束后点击画面 |

角色自动向右奔跑，你要做的是：**跳过深渊缺口、吃金币、踩扁史莱姆**，活得越久分数越高。踩怪要从上方落下踩中，侧面撞到会扣血。连续吃金币/踩怪会累积 Combo，三条命耗尽即结算，最高分自动保存到本地。

## 计分与生命规则

| 项目 | 得分 / 规则 |
|------|-------------|
| 奔跑距离 | 每前进 1 像素 +0.12 分（距离越远分越高） |
| 金币 | 每枚 +10 分 × 连击倍率 |
| 踩怪 | 每只 +25 分 × 连击倍率（须从上方踩中） |
| 连击倍率 | `1 + ⌊combo ÷ 5⌋`，即 5 连击 ×2、10 连击 ×3…… |
| 连击时效 | 2.2 秒内未拾取金币/踩怪则连击清零 |
| 生命 | 初始 3 条，撞怪侧面或坠入深渊各扣 1 条 |
| 受伤无敌 | 扣血后 1.2 秒无敌（角色闪烁），避免连续掉血 |
| 坠崖重生 | 掉出画面后扣血并回到最近站立的平台上方继续跑 |
| 速度递增 | 随距离从 150 px/s 逐步加速到上限 255 px/s |

> 小技巧：连击倍率对踩怪收益很可观，攒到 5 连击后再连续踩怪能快速拉分。

## 可调参数表

全部集中在 `index.html` 顶部 `CONFIG` 区，改完保存刷新即可生效：

| 参数 | 默认值 | 效果 |
|------|--------|------|
| `GRAVITY` | 1350 | 重力，越大下落越快 |
| `JUMP_V` | -360 | 起跳速度，绝对值越大跳越高 |
| `JUMP2_V` | -300 | 二段跳速度 |
| `STOMP_V` | -270 | 踩怪后的弹起速度 |
| `RUN_BASE` / `RUN_MAX` | 150 / 255 | 起始 / 最高奔跑速度 |
| `COYOTE` | 0.10 | 土狼时间，离开平台后仍可起跳的宽限 |
| `JUMP_BUF` | 0.12 | 跳跃缓冲，落地前提前按键的容错 |
| `JUMP_CUT` | 0.45 | 松手短跳系数，用于区分高跳/短跳 |
| `MAX_LIVES` | 3 | 生命数 |
| `INVULN` | 1.2 | 受伤后无敌秒数 |
| `GAP_MIN` / `GAP_MAX` | 28 / 68 | 平台缺口宽度，越大越难 |
| `SEG_W_MIN` / `SEG_W_MAX` | 90 / 190 | 平台段的宽度范围 |
| `GROUND_MIN` / `GROUND_MAX` | 150 / 218 | 地面高度起伏范围 |
| `TILE` | 16 | 像素瓦片基准尺寸 |
| `STEP` | 1/60 | 固定物理步长（60Hz） |

配色集中在 `C` 调色板对象里，背景视差、落日、城市灯光等视觉元素均可自由调整。

## 技术实现

- **固定步长物理循环**：累加器驱动 `update(STEP)`，渲染与物理解耦，避免高刷屏速度异常和低帧率穿模。
- **程序化无限地形**：按视野动态生成平台段（`generateAhead`），离开视野的段/金币/怪物自动回收（`recycle`），内存不随游玩时长增长。
- **手感调优**：土狼时间 + 跳跃缓冲 + 可变跳跃高度（松手短跳）+ 二段跳。
- **单向平台碰撞**：仅在下落时检测平台顶面，从下方跳跃可穿过，配合分轴约束避免卡墙。
- **程序化音效**：Web Audio API 实时合成跳跃、金币、踩怪、受伤、死亡等音效，外加一段 8-bit 循环背景旋律，无任何外部素材依赖。
- **视差像素背景**：星空闪烁、落日、远山（0.15）、近山（0.32）、城市剪影（0.5）多层视差滚动，叠加 CRT 扫描线滤镜。
- **粒子与反馈**：拾取/踩踏/受伤粒子爆发、浮字、屏幕震动、受击闪白、命中慢动作。
- **全端自适应**：键盘 + 触屏 + 鼠标统一输入层；逻辑分辨率 480×270 整数放大，`image-rendering: pixelated` 保持像素锐利；viewport 禁止缩放，适配移动端刘海屏。

## 本地运行与部署

- **本地**：直接双击 `index.html`，或拖入任意现代浏览器（Chrome / Edge / Firefox / Safari）。
- **部署**：因为是纯静态单文件，可直接丢到 GitHub Pages、Cloudflare Pages、Gitee Pages 或任意静态托管，无需构建步骤。
- **本地起服务（可选）**：`python -m http.server 8000`，然后访问 `http://localhost:8000/index.html`。

## 已知限制

- 音效依赖浏览器 Web Audio，首次点击/按键后才会解锁发声（浏览器策略，属正常现象）。
- 逻辑分辨率固定 480×270 放大渲染，在超宽屏上画面居中显示、两侧留黑边。
- 最高分存于 `localStorage`，清理浏览器数据后会重置。
- 纯单机，无联网排行榜。
